# Real Estate Property Management Platform

Desktop based management application built with Python and Tkinter to track a rental portfolio.

## Features
- Visual Table Display 
- automated Lease Calculation
- JSON Local Database

## Project Structure
- 'main.py': Core Tkinter graphical user interface (GUI)
- 'models.py': Object oriented handling of data for file input.output
- 'database.json': Local database
